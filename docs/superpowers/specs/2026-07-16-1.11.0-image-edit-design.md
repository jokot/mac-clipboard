# MaClip 1.11.0 — Image Editor — Design

**Date:** 2026-07-16
**Status:** Implemented. Amended on 2026-10-21 after QA. See "Amendments".
**Target version:** 1.11.0 (build 15)
**Branch:** feature/1.11.0-image-edit

## Summary

Image clips become editable. Right-click an image clip → **Edit…** opens a separate editor window with a canvas + toolbar. User can crop, rotate, annotate (arrow / rectangle / oval / text / freehand pen), redact regions (opaque black), undo/redo (⌘Z / ⌘⇧Z), and commit either **Save** (in place, preserves clip id/date) or **Save as new** (fresh clip on top). All output re-encrypts via existing `HistoryCrypto.seal` and writes a new `.enc` file.

The overlay stays a fixed 520×600 window. The first build made it resizable. That change was removed (see "Amendments").

## Amendments (2026-10-21)

QA found problems with the approved design. These changes apply. The sections below are updated to match.

| # | Approved design | Implemented | Reason |
|---|---|---|---|
| 1 | Sheet over the overlay | Separate floating window (`ImageEditorWindowController`). Default 1020×720, minimum 940×600. The window saves its frame. | A sheet cannot be wider than its parent. The 520 pt overlay cut off the toolbar. |
| 2 | Overlay resizable, size saved in `AppSettings` | Removed. Overlay is fixed at 520×600. | Product decision: keep the 1.10.x overlay behavior. |
| 3 | Overlay stays open while editing | Edit… hides the overlay. On close, focus goes back to the previous app. | MaClip excludes its own copies. When MaClip stays frontmost, the next screenshot is dropped. |
| 4 | Crop mode with **Apply** and **Clear** | The crop applies on mouse-up. The crop tool shows the full image, dims the removed area and outlines the crop. Other tools show only the crop. | Simpler. Undo replaces Clear. |
| 5 | Crop stored in rotated coordinates, rotate re-maps the crop | Crop and layers are stored in unrotated base-image coordinates. Order: crop, then rotate. `CanvasGeometry` and `ImageCompositor` use the same order. | One coordinate space. No re-map step. |
| 6 | Stroke width 1 / 2 / 4 / 8 pt | Slider 1–12 pt, step 1 | Finer control. |
| 7 | Save as new is not concealed | Save as new copies `isConcealed` and `concealedExpiresAt` from the source clip | An edited copy of a secret is still a secret. |
| 8 | Esc cancels the active draft, if any | Esc during a drag cancels that shape. Esc in the text field discards the text. Esc at other times closes the editor. | Same intent, now specified per case. |

The same release changes the default history limit from 100 to 50 (`AppSettings.defaultMaxItems`).

## Wedge

Screenshot workflow. Capture → crop → annotate → paste — currently users leave MaClip for Preview/Skitch. Editor closes the loop inside history.

## Scope

**In scope:**
- Separate floating editor window. The overlay hides while the editor is open.
- Base image sourced from either `.memory` (in-RAM NSImage) or `.file(URL)` (decrypted via existing `imageData(at:)`).
- Transforms: crop (draggable rectangle), rotate 90° CW/CCW.
- Annotation tools: arrow, rectangle (stroke), oval (stroke), text (single-line, one font size, click-place then type), freehand pen (mouse/trackpad drag stroke).
- Redact tool: opaque black rectangle. No blur.
- Color picker (accent presets: red, orange, yellow, green, blue, purple, black, white) + stroke width slider (1–12 pt).
- Undo/redo: in-editor state stack, ⌘Z pop, ⌘⇧Z push forward, cap 20 states.
- **Save** (in place): reuses `ClipboardListViewModel.replaceContent(of:with:)`. New PNG re-encrypted; old `.enc` file deleted if source was `.file` and URL differs.
- **Save as new**: new `ClipboardItem` with fresh UUID + date, same `sourceBundleID`, `isConcealed` and `concealedExpiresAt`, inserted at top of `items` via `viewModel.insertImage(pngData:from:)`. Original untouched.
- Cancel (Esc), or the window close button: discards all edits, closes the editor.
- Bump to 1.11.0 (build 15).

**Out of scope for 1.11.0:**
- Blur redact.
- Highlighter tool.
- Callouts, stickers, custom shapes.
- Image resize / format conversion (JPEG output).
- Layer selection / re-ordering / delete of specific past layer (only stack-undo).
- Text formatting (bold/italic/font choice).
- Multi-line text.
- Batch edit.
- Vector export.

## Architecture

| File | Responsibility |
|---|---|
| `Views/ImageEditor/ImageEditorWindowController.swift` | Floating `NSWindow` that hosts `ImageEditorSheet`. Runs the save handlers. Calls `onClose` for every close path. Brings an open editor to the front instead of opening a second one. |
| `Views/ImageEditor/ImageEditorSheet.swift` | SwiftUI editor content: toolbar, canvas, keyboard shortcuts, save-failure alert |
| `Views/ImageEditor/ImageEditorViewModel.swift` | `@ObservableObject`, holds `ImageEditState`, undo/redo stacks, the text draft and the drag-cancel state |
| `Views/ImageEditor/EditLayer.swift` | `EditLayer` enum + `EditTool` enum + `StrokeStyle` (not persisted) |
| `Views/ImageEditor/CanvasView.swift` | SwiftUI `Canvas` renderer: draws base image, all committed layers, current draft layer; forwards drag/click gestures. `CanvasGeometry` maps base-image space to the view (crop, rotate, fit). |
| `Utilities/ImageCompositor.swift` | Pure: `compose(state: ImageEditState) -> Data?` — offscreen `NSBitmapImageRep`, flips to a top-left origin, applies crop → rotation → base → layers → PNG data |
| `Services/ClipboardRepository.swift` | Add `deleteImage(at: URL)` helper (for in-place save cleanup). |
| `ViewModels/ClipboardListViewModel.swift` | Add `insertImage(pngData:from:) -> Bool` for save-as-new; add `saveEditedImage(replacing:pngData:) -> Bool` for in-place. Both go through `repository.saveImage`. Both return false when the write fails. |
| `Views/Components/ClipboardItemRow.swift` | Image clips get Edit… menu; new `onEditImage: ((ClipboardItem) -> Void)?` callback (separate from text edit flow). |
| `Views/ContentView.swift` | Loads the image, applies the 4096 px guard, then calls `onEditImage(item, image)`. |
| `App/OverlayWindow.swift` | Owns `ImageEditorWindowController`. Hides the overlay (no refocus) when the editor opens. Refocuses the previous app when the editor closes. |
| `Models/AppSettings.swift` | `defaultMaxItems = 50`. No overlay size settings. |
| `project.yml` | `CURRENT_PROJECT_VERSION: 15`, `MARKETING_VERSION: 1.11.0`. |

## Data model

```swift
enum EditTool: String, CaseIterable {
    case crop, arrow, rectangle, oval, text, pen, redact
}

struct StrokeStyle: Equatable {
    var color: Color
    var width: CGFloat
}

enum EditLayer: Equatable {
    case arrow(from: CGPoint, to: CGPoint, style: StrokeStyle)
    case rectangle(frame: CGRect, style: StrokeStyle)
    case oval(frame: CGRect, style: StrokeStyle)
    case text(origin: CGPoint, string: String, color: Color, fontSize: CGFloat)
    case pen(points: [CGPoint], style: StrokeStyle)
    case redact(frame: CGRect)  // always opaque black
}

struct ImageEditState: Equatable {
    var baseImage: NSImage        // decrypted when the editor opens
    var layers: [EditLayer]
    var cropRect: CGRect?         // in unrotated base-image coords, top-left origin (nil = full)
    var rotationQuarterTurns: Int // 0/1/2/3
}
```

**No persistence of `ImageEditState`.** The editor is transient. Only the composed PNG survives.

## Undo/redo

`ImageEditorViewModel`:
```swift
private var undoStack: [ImageEditState] = []
private var redoStack: [ImageEditState] = []
private let cap = 20

func mutate(_ change: (inout ImageEditState) -> Void) {
    undoStack.append(state)
    if undoStack.count > cap { undoStack.removeFirst() }
    redoStack.removeAll()
    change(&state)
}

func undo() {
    guard let prev = undoStack.popLast() else { return }
    redoStack.append(state)
    state = prev
}

func redo() {
    guard let next = redoStack.popLast() else { return }
    undoStack.append(state)
    state = next
}
```

Layer commits, crop, rotate all go through `mutate {}`. Mid-drag drafts do NOT push undo — only on gesture end.

## Compositor

```swift
enum ImageCompositor {
    static func compose(_ state: ImageEditState) -> Data? {
        // 1. outSize = rotated(cropRect ?? baseBounds)
        // 2. NSBitmapImageRep(pixelsWide: ..., pixelsHigh: ..., bitsPerSample: 8, samplesPerPixel: 4, hasAlpha: true, isPlanar: false, colorSpaceName: .deviceRGB, bytesPerRow: 0, bitsPerPixel: 32)
        // 3. NSGraphicsContext.saveGraphicsState; set current to rep-backed context.
        // 4. Flip to a top-left origin (y down). Translate to output center; rotate
        //    (positive angle = clockwise); translate back; translate by -cropRect.origin.
        // 5. Draw base image at .zero, size = base.size.
        // 6. For each layer: draw via NSBezierPath / NSAttributedString.draw(at:).
        // 7. Restore graphics state.
        // 8. rep.representation(using: .png, properties: [:]) → Data.
    }
}
```

Layer drawing:
- **arrow**: line from → to; arrowhead = 2 short lines at `to` at ±30° from line direction, length = 4 × style.width.
- **rectangle** / **oval**: `NSBezierPath` with stroke, no fill.
- **text**: `NSAttributedString` with `[.font: NSFont.systemFont(ofSize: fontSize), .foregroundColor: NSColor(color)]`, drawn at `origin`.
- **pen**: `NSBezierPath` connecting points via `line(to:)`; round line cap/join.
- **redact**: `NSBezierPath` rectangle filled with `NSColor.black.setFill()`.

## Editor window UI

```
┌── Toolbar (48pt) ────────────────────────────────────────────────────────┐
│ [Crop] [↺] [↻] │ [Arr][Rect][Oval][T][Pen][●Redact] │ 🎨 ━━ │ ↶ ↷  Cancel  Save  Save as new │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│                         Canvas (fills remaining)                         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

Window size: 1020×720 by default, 940×600 minimum, resizable. The window floats, like Settings. Canvas letterboxes the image to preserve aspect ratio.

**Tool interactions:**
- **Crop tool**: shows the full image. Drag draws a dashed rectangle. Mouse up → `state.cropRect = rect` via `mutate {}`, limited to the image bounds. The area outside the crop is dimmed. Other tools show only the cropped area. Undo removes a crop.
- **Arrow / Rect / Oval / Redact**: mouse down = start point; drag = update draft; mouse up = commit as layer via `mutate {}`.
- **Text**: click to place origin; inline `TextField` opens at origin with keyboard focus; Return → commit; Esc → discard. The draft lives in `ImageEditorViewModel`. Save commits a pending draft first. A click elsewhere or a tool change also commits it.
- **Pen**: mouse down = new pen layer with first point; drag = append points to draft; mouse up = commit.
- **Rotate CW / CCW**: buttons apply immediately via `mutate {}`. `cropRect` does not change, because it is in unrotated coordinates.

**Keyboard:**
- ⌘Z undo, ⌘⇧Z redo
- Esc: during a drag, cancel that shape. In the text field, discard the text. Otherwise close the editor (Cancel).
- Return: commit the text draft. With no text draft, Return is Save.
- Number keys 1-8: quick color pick (red/orange/yellow/green/blue/purple/black/white). Only in the editor window, and not while the text field has focus.

## Save flow

### Save (in place)
```swift
vm.commitText(color:fontSize:)   // pending text becomes a layer
guard let data = ImageCompositor.compose(state),
      onCommit(data, .inPlace)   // -> viewModel.saveEditedImage(...)
else { show "Could not save image"; keep the editor open; return }
// success: the window closes
```

VM:
```swift
func saveEditedImage(replacing item: ClipboardItem, pngData: Data) -> Bool {
    guard let url = repository.saveImage(pngData: pngData) else { return false }
    guard replaceContent(of: item, with: .image(...url...)) != nil else {
        repository.deleteImage(at: url)   // clip left the list while editing
        return false
    }
    // If original was .file(oldURL), delete oldURL.enc via repository.deleteImage(at: oldURL).
    // (replaceContent preserves id/date/source/concealed/OCR.)
    return true
}
```

### Save as new
```swift
func insertImage(pngData: Data, from source: ClipboardItem) -> Bool {
    guard let url = repository.saveImage(pngData: pngData) else { return false }
    let item = ClipboardItem(
        date: Date(), content: .image(...url...),
        sourceBundleID: source.sourceBundleID,
        isConcealed: source.isConcealed,
        concealedExpiresAt: source.concealedExpiresAt,
        isOCRResult: false
    )
    items.insert(item, at: 0)
    applyMaxItems(AppSettings.shared.maxItems)
    repository.saveToDiskAsync(items: items)
    ContentTagDetector.clearCache()
    return true
}
```

## Edge cases

1. **Crop smaller than 1 px, or fully outside the image** → ignored.
2. **Crop after rotation** → the drag maps back to unrotated base coordinates through `CanvasGeometry`. The crop rect is stored there.
3. **Rotate after crop** → `cropRect` does not change. The compositor crops, then rotates.
4. **Unchanged state on Save** → `isDirty` computed prop; if false, Save button disabled. `isDirty = layers.count > 0 || cropRect != nil || rotationQuarterTurns != 0`.
5. **Save on concealed clip** → new PNG inherits `isConcealed` + `concealedExpiresAt` via `replaceContent`.
6. **Very large image (>4096 px)** → reject with alert "Image too large to edit in v1.11.0 (max 4096 px)."; the editor does not open. Follow-up 1.11.1: tiling.
7. **Auto-dismiss during edit** → not possible. The overlay is hidden and its idle timer is stopped while the editor is open.
8. **Save fails (disk full / crypto)** → alert "Could not save image"; the editor stays open with its state.
9. **Clip leaves the list while editing** (deleted, or pushed out by the history limit) → Save fails as in 8. The new image file is deleted.
10. **Multiple monitors** → the editor window restores its last frame (`setFrameAutosaveName`).
11. **Edit… while the editor is open** → the open editor comes to the front. Its edits stay.
12. **Screenshot right after Save** → captured. Focus goes back to the previous app when the editor closes.
