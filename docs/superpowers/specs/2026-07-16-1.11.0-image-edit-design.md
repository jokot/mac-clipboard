# MaClip 1.11.0 — Image Editor — Design

**Date:** 2026-07-16
**Status:** Approved (pending implementation plan)
**Target version:** 1.11.0 (build 15)
**Branch:** feature/1.11.0-image-edit

## Summary

Image clips become editable. Right-click an image clip → **Edit…** opens a full sheet over the overlay containing a canvas + toolbar. User can crop, rotate, annotate (arrow / rectangle / oval / text / freehand pen), redact regions (opaque black), undo/redo (⌘Z / ⌘⇧Z), and commit either **Save** (in place, preserves clip id/date) or **Save as new** (fresh clip on top). All output re-encrypts via existing `HistoryCrypto.seal` and writes a new `.enc` file.

Overlay window becomes **user-resizable** in this release so the image editor sheet has real canvas space. Chosen width/height persists across launches via `AppSettings`.

## Wedge

Screenshot workflow. Capture → crop → annotate → paste — currently users leave MaClip for Preview/Skitch. Editor closes the loop inside history.

## Scope

**In scope:**
- Sheet UI over overlay (modal within app, does not push overlay behind other apps).
- Base image sourced from either `.memory` (in-RAM NSImage) or `.file(URL)` (decrypted via existing `imageData(at:)`).
- Transforms: crop (draggable rectangle), rotate 90° CW/CCW.
- Annotation tools: arrow, rectangle (stroke), oval (stroke), text (single-line, one font size, click-place then type), freehand pen (mouse/trackpad drag stroke).
- Redact tool: opaque black rectangle. No blur.
- Color picker (accent presets: red, orange, yellow, green, blue, purple, black, white) + stroke width slider (1 / 2 / 4 / 8 pt).
- Undo/redo: in-editor state stack, ⌘Z pop, ⌘⇧Z push forward, cap 20 states.
- **Save** (in place): reuses `ClipboardListViewModel.replaceContent(of:with:)`. New PNG re-encrypted; old `.enc` file deleted if source was `.file` and URL differs.
- **Save as new**: new `ClipboardItem` with fresh UUID + date, same `sourceBundleID`, inserted at top of `items` via new `viewModel.insertImage(...)`. Original untouched.
- Cancel (Esc): discards all edits, closes sheet.
- **Overlay window resizable + size persistence**:
  - Add `.resizable` to overlay `styleMask`.
  - Min size: 480×480 (current minimum from `ContentView.frame(minWidth:minHeight:)`). No max.
  - `AppSettings.overlayWidth` / `overlayHeight` — persisted via existing `@Published` + `UserDefaults` didSet pattern. Defaults 520×600.
  - Read persisted size on overlay show; write live size on `NSWindow.didResizeNotification` (debounced or on-end).
- Bump to 1.11.0 (build 15).

**Out of scope for 1.11.0:**
- Blur redact.
- Highlighter tool.
- Callouts, stickers, custom shapes.
- Image resize / format conversion (JPEG output).
- Layer selection / re-ordering / delete of specific past layer (only stack-undo).
- Text formatting (bold/italic/font choice).
- Multi-line text.
- Batch edit.
- Vector export.

## Data model

```swift
enum EditTool: String, CaseIterable {
    case crop, arrow, rectangle, oval, text, pen, redact
}

struct StrokeStyle: Equatable {
    var color: Color
    var width: CGFloat
}

enum EditLayer: Equatable {
    case arrow(from: CGPoint, to: CGPoint, style: StrokeStyle)
    case rectangle(frame: CGRect, style: StrokeStyle)
    case oval(frame: CGRect, style: StrokeStyle)
    case text(origin: CGPoint, string: String, color: Color, fontSize: CGFloat)
    case pen(points: [CGPoint], style: StrokeStyle)
    case redact(frame: CGRect)  // always opaque black
}

struct ImageEditState: Equatable {
    var baseImage: NSImage        // decrypted at sheet open
    var layers: [EditLayer]
    var cropRect: CGRect?         // in current base-image coords (nil = full)
    var rotationQuarterTurns: Int // 0/1/2/3
}
```

**No persistence of `ImageEditState`.** Sheet is transient. Only the composed PNG survives.

## Undo/redo

`ImageEditorViewModel`:
```swift
private var undoStack: [ImageEditState] = []
private var redoStack: [ImageEditState] = []
private let cap = 20

func mutate(_ change: (inout ImageEditState) -> Void) {
    undoStack.append(state)
    if undoStack.count > cap { undoStack.removeFirst() }
    redoStack.removeAll()
    change(&state)
}

func undo() {
    guard let prev = undoStack.popLast() else { return }
    redoStack.append(state)
    state = prev
}

func redo() {
    guard let next = redoStack.popLast() else { return }
    undoStack.append(state)
    state = next
}
```

Layer commits, crop-apply, rotate all go through `mutate {}`. Mid-drag drafts do NOT push undo — only on gesture end.

## Compositor

```swift
enum ImageCompositor {
    static func compose(_ state: ImageEditState) -> Data? {
        // 1. outSize = rotated(cropRect ?? baseBounds)
        // 2. NSBitmapImageRep(pixelsWide: ..., pixelsHigh: ..., bitsPerSample: 8, samplesPerPixel: 4, hasAlpha: true, isPlanar: false, colorSpaceName: .deviceRGB, bytesPerRow: 0, bitsPerPixel: 32)
        // 3. NSGraphicsContext.saveGraphicsState; set current to rep-backed context.
        // 4. Translate to output center; rotate; translate back; translate by -cropRect.origin.
        // 5. Draw base image at .zero, size = base.size.
        // 6. For each layer: draw via NSBezierPath / NSAttributedString.draw(at:).
        // 7. Restore graphics state.
        // 8. rep.representation(using: .png, properties: [:]) → Data.
    }
}
```

Layer drawing:
- **arrow**: line from → to; arrowhead = 2 short lines at `to` at ±30° from line direction, length = 4 × style.width.
- **rectangle** / **oval**: `NSBezierPath` with stroke, no fill.
- **text**: `NSAttributedString` with `[.font: NSFont.systemFont(ofSize: fontSize), .foregroundColor: NSColor(color)]`, drawn at `origin`.
- **pen**: `NSBezierPath` connecting points via `line(to:)`; round line cap/join.
- **redact**: `NSBezierPath` rectangle filled with `NSColor.black.setFill()`.

## Sheet UI

```
┌── Toolbar (48pt) ────────────────────────────────────────────────────────┐
│ [Crop] [↺] [↻] │ [Arr][Rect][Oval][T][Pen][●Redact] │ 🎨 ━━ │ ↶ ↷  Cancel  Save  Save as new │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│                         Canvas (fills remaining)                         │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

Sheet size: 800×600 minimum, resizable. Canvas letterboxes image to preserve aspect ratio.

**Tool interactions:**
- **Crop mode**: dashed overlay rectangle. Drag creates/adjusts. Toolbar shows **Apply** and **Clear**. Apply → `state.cropRect = rect` via `mutate {}`; exit crop mode. Clear → `state.cropRect = nil`.
- **Arrow / Rect / Oval / Redact**: mouse down = start point; drag = update draft; mouse up = commit as layer via `mutate {}`.
- **Text**: click to place origin; inline `TextField` opens at origin; Enter → commit; Esc → cancel draft.
- **Pen**: mouse down = new pen layer with first point; drag = append points to draft; mouse up = commit.
- **Rotate CW / CCW**: buttons apply immediately via `mutate {}`. `cropRect` (if any) gets re-mapped via 90° coordinate swap on rotated base bounds.

**Keyboard:**
- ⌘Z undo, ⌘⇧Z redo
- Esc: cancel active draft; if none, close sheet (Cancel)
- Return: commit active text draft
- Number keys 1-8: quick color pick (red/orange/yellow/green/blue/purple/black/white)

## Save flow

### Save (in place)
```swift
guard let data = ImageCompositor.compose(state) else { showError; return }
viewModel.saveEditedImage(replacing: originalItem, pngData: data)
```

VM:
```swift
func saveEditedImage(replacing item: ClipboardItem, pngData: Data) {
    let newContent = repository.saveImage(pngData)  // encrypts, returns .image(...)
    replaceContent(of: item, with: newContent)
    // If original was .file(oldURL), delete oldURL.enc via repository.deleteImage(at: oldURL).
    // (replaceContent preserves id/date/source/concealed/OCR.)
}
```

### Save as new
```swift
func insertImage(pngData: Data, sourceBundleID: String?) {
    let content = repository.saveImage(pngData)
    let item = ClipboardItem(
        date: Date(), content: content,
        sourceBundleID: sourceBundleID,
        isConcealed: false,
        concealedExpiresAt: nil,
        isOCRResult: false
    )
    items.insert(item, at: 0)
    applyMaxItems(AppSettings.shared.maxItems)
    repository.saveToDiskAsync(items: items)
    ContentTagDetector.clearCache()
}
```

## Edge cases

1. **Empty crop rect on Apply** → ignore, stay in crop mode.
2. **Crop after rotation** → crop rect stored in ROTATED base coords; compositor applies rotation before crop translation. Coord order in code: rotate → crop.
3. **Rotate after crop applied** → `mutate` re-maps `cropRect` via 90° swap; keeps geometry consistent.
4. **Unchanged state on Save** → `isDirty` computed prop; if false, Save button disabled. `isDirty = layers.count > 0 || cropRect != nil || rotationQuarterTurns != 0`.
5. **Save on concealed clip** → new PNG inherits `isConcealed` + `concealedExpiresAt` via `replaceContent`.
6. **Very large image (>4096 px)** → reject with alert "Image too large to edit in v1.11.0"; sheet doesn't open. Follow-up 1.11.1: tiling.
7. **Auto-dismiss during edit** → sheet blocks overlay idle timer while presented.
8. **Save fails (disk full / crypto)** → alert; sheet stays open with state.
9. **Sheet closes via overlay hide** → treat as Cancel; discard edits (no confirm — YAGNI).
10. **Multiple monitors** → sheet centers on overlay's screen (SwiftUI default).
