# MaClip 1.10.1 — Edit Clip Content — Design

**Date:** 2026-05-18
**Status:** Approved (pending implementation plan)
**Target version:** 1.10.1 (build 14)
**Branch:** feature/1.10.1-edit

## Summary

Right-click a clip → **Edit…** opens an inline editor inside the row. Supports text, URL, and file content (image edit out of scope). The row expands to host a `TextEditor` that fills up to half the overlay's height with internal scrolling beyond that. Cancel and Save buttons commit or discard. Save updates the clip in place — same `id`, `date`, and `sourceBundleID` are preserved. The pasteboard is not touched; user must re-click the row to paste the edited content.

## Wedge

Content control. Capture → encryption → new content kinds → editability. Once captured, clips become mutable. Useful for fixing typos, redacting before pasting, repurposing snippets.

## Scope

**In scope:**
- Inline edit mode for `.text`, `.url`, `.file` content.
- Image clips do NOT have an Edit action.
- `Edit…` action surfaces in the unified `ClipboardItemRow` context menu (above the Exclude block, below content-specific actions).
- Inline `TextEditor` UI; row expands. `maxHeight: 240` for the editor area (half the default 480pt minimum overlay height) with internal `ScrollView` beyond that. Minimum editor height: 80pt.
- Cancel + Save buttons; `.cancelAction` (Esc) cancels, `.defaultAction` (⌘↩) saves.
- In-place update: existing `ClipboardItem` is replaced in `items[idx]` with one carrying the new content but the same id/date/sourceBundleID/concealed/OCR flags.
- File clip editing: text area shows one path per line; on save, parse lines back to `[URL]` via `URL(fileURLWithPath:)`, skip empty lines. Reject save if zero non-empty paths remain (inline red caption).
- URL clip editing: text area shows the absolute string; on save, parse via `URL(string:)`. Reject if parse returns nil.
- Text clip editing: trivial — string in, string out (empty allowed).
- `ContentTagDetector.clearCache()` after every edit so tag/icon re-detects.
- Bump version to 1.10.1 (build 14).

**Out of scope:**
- Image edit.
- Markdown / syntax preview during edit.
- Multi-clip edit.
- Undo/redo history across edits (TextEditor's built-in undo handles within-session).
- Edit hotkey from list-row selection (right-click only).

## Data Model

No persistence schema change. Editing only updates the `content` field on an existing `ClipboardItem`. Helper on `ClipboardListViewModel`:

```swift
@discardableResult
func replaceContent(of item: ClipboardItem, with newContent: ClipboardItemContent) -> ClipboardItem? {
    guard let idx = items.firstIndex(where: { $0.id == item.id }) else { return nil }
    let existing = items[idx]
    let updated = ClipboardItem(
        id: existing.id,
        date: existing.date,
        content: newContent,
        sourceBundleID: existing.sourceBundleID,
        isConcealed: existing.isConcealed,
        concealedExpiresAt: existing.concealedExpiresAt,
        isOCRResult: existing.isOCRResult
    )
    items[idx] = updated
    repository.saveToDiskAsync(items: items)
    ContentTagDetector.clearCache()
    return updated
}
```

## Row UI (Editing Mode)

`ClipboardItemRow` gains:

```swift

@State private var editText: String = ""
@State private var editError: String? = nil
```

New callback property:

```swift
var onEdit: ((ClipboardItem, ClipboardItemContent) -> Void)? = nil
```

Menu entry (insert in `.contextMenu` ABOVE the Exclude block):

```swift
if canEdit(item.content) {
    Button("Edit…") { enterEditMode() }
}
```

Helpers:

```swift
private func canEdit(_ content: ClipboardItemContent) -> Bool {
    switch content {
    case .text, .url, .file: return true
    case .image:             return false
    }
}

private func enterEditMode() {
    editText = currentContentAsText(item.content)
    editError = nil
    isEditing = true
}

private func currentContentAsText(_ content: ClipboardItemContent) -> String {
    switch content {
    case .text(let s):  return s
    case .url(let u):   return u.absoluteString
    case .file(let us): return us.map(\.path).joined(separator: "\n")
    case .image:        return ""
    }
}

private func commitEdit() {
    switch item.content {
    case .text:
        onEdit?(item, .text(editText))
        isEditing = false
    case .url:
        let trimmed = editText.trimmingCharacters(in: .whitespacesAndNewlines)
        guard let u = URL(string: trimmed) else {
            editError = "Not a valid URL"
            return
        }
        onEdit?(item, .url(u))
        isEditing = false
    case .file:
        let lines = editText.split(separator: "\n", omittingEmptySubsequences: true)
        let urls = lines.map { URL(fileURLWithPath: String($0).trimmingCharacters(in: .whitespacesAndNewlines)) }
        guard !urls.isEmpty else {
            editError = "Need at least one path"
            return
        }
        onEdit?(item, .file(urls))
        isEditing = false
    case .image:
        isEditing = false
    }
}
```

Body swap:

```swift
var body: some View {

}
```

`EditorView`:

```swift
private struct EditorView: View {
    @Binding var text: String
    @Binding var error: String?
    let onCancel: () -> Void
    let onSave: () -> Void

    var body: some View {
        VStack(alignment: .leading, spacing: 8) {
            ScrollView {
                TextEditor(text: $text)
                    .font(.body)
                    .frame(minHeight: 80)
            }
            .frame(maxHeight: 240)
            .overlay(
                RoundedRectangle(cornerRadius: 6)
                    .stroke(Color.secondary.opacity(0.3), lineWidth: 1)
            )
            if let error = error {
                Text(error)
                    .font(.caption)
                    .foregroundColor(.red)
            }
            HStack {
                Spacer()
                Button("Cancel", action: onCancel)
                    .keyboardShortcut(.cancelAction)
                Button("Save", action: onSave)
                    .keyboardShortcut(.defaultAction)
            }
        }
    }
}
```

## Edge Cases

1. **Auto-dismiss + edit** — typing in TextEditor fires `keyDown` events; existing local monitor resets the idle timer. Overlay stays open while editing.
2. **Concealed clip edit** — text area shows real content (same as reveal behavior). After save, clip remains concealed; preview re-masks with `••••••`.
3. **Empty text save** — allowed.
4. **Tags re-detect** — `ContentTagDetector.clearCache()` post-save means the row's icon (primaryTag-derived) updates next render.
5. **OCR result edit** — `isOCRResult` preserved; row still shows OCR badge.
6. **Cancel** — `isEditing = false` discards `editText`. No persistence happens.
7. **Long content (~100k chars)** — internal ScrollView handles. TextEditor is performant enough.
8. **File path edit producing a non-existent path** — accepted; stale-file detection from 1.10.0 takes over after save.
9. **URL edit producing nil URL** — inline error caption; row stays in edit mode.
10. **Edit then close overlay** — if user closes overlay (Esc not pressed but overlay hidden some other way), the in-flight edit is lost. Acceptable for v1.

## Testing

### Unit tests (extend `ClipboardListViewModelTests`)

```swift
@MainActor
func test_replaceContentPreservesIdentity() async {
    AppSettings.shared.maxItems = 10
    AppSettings.shared.autoCleanEnabled = false

    let repo = MockRepo()
    let monitor = MockMonitor()
    let vm = ClipboardListViewModel(repository: repo, monitor: monitor)

    let original = ClipboardItem(
        date: Date(),
        content: .text("original"),
        sourceBundleID: "com.apple.TextEdit",
        isConcealed: false,
        concealedExpiresAt: nil,
        isOCRResult: false
    )
    monitor.emit(original)

    await MainActor.run {
        let inserted = vm.items[0]
        let updated = vm.replaceContent(of: inserted, with: .text("edited"))
        XCTAssertNotNil(updated)
        XCTAssertEqual(updated?.id, inserted.id)
        XCTAssertEqual(updated?.date, inserted.date)
        XCTAssertEqual(updated?.sourceBundleID, "com.apple.TextEdit")
        if case .text(let t) = updated?.content {
            XCTAssertEqual(t, "edited")
        } else { XCTFail("expected text content") }
    }
}

@MainActor
func test_replaceContentSavesToRepository() async {
    AppSettings.shared.maxItems = 10
    AppSettings.shared.autoCleanEnabled = false

    let repo = MockRepo()
    let monitor = MockMonitor()
    let vm = ClipboardListViewModel(repository: repo, monitor: monitor)

    monitor.emit(ClipboardItem(date: Date(), content: .text("a")))

    await MainActor.run {
        repo.saveAsyncCount = 0
        let inserted = vm.items[0]
        vm.replaceContent(of: inserted, with: .text("b"))
        XCTAssertGreaterThan(repo.saveAsyncCount, 0)
    }
}
```
